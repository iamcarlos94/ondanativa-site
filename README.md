# Onda Nativa

Página institucional da Onda Nativa, agência de influencer marketing que aproxima marcas e creators. Uma iniciativa Pulso Social.

## Publicação

O site é publicado automaticamente no GitHub Pages sempre que a branch `main` recebe alterações.

## Conteúdo

- `index.html`: texto e estrutura da página
- `styles.css`: identidade visual e apresentação responsiva
- `assets/`: imagens e ícone do site

Domínio pretendido: [ondanativa.com](https://ondanativa.com/)
